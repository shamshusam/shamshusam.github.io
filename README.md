# Shamshuddin Sam — Personal Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS, and JavaScript.

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your professional email address.
3. Update the LinkedIn and Instagram links to your exact profile URLs.
4. Review the education, experience, and project descriptions; edit anything that is not accurate.
5. If you have a resume PDF, place it in this folder and add a link to it in the navigation or contact section.
6. If you want a photo, add your own image and update the hero section. The current design uses an abstract graphic and does not require a photo.

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository named `shamshusam.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)` if prompted.
4. Wait for GitHub Pages to publish. Your site URL will be `https://shamshusam.github.io/`.

If that repository name is already used by another site, choose another repository name and enable Pages in Settings → Pages. The URL will then be based on the repository name.
